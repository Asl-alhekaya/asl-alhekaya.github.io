Connect the channel's TikTok account

This page is used by the channel owner only. It connects the channel's own TikTok account so that a finished episode video can be sent to that account's TikTok inbox as a draft. The owner reviews and publishes it inside the TikTok app. Nothing is ever posted automatically, and no other person's account is connected.

1 · Connect code

The channel owner asks the channel's private bot for a one-time code (valid 10 minutes) and types it here. Without a valid code the connection is refused.

What the app asks TikTok for

  • user.info.basic — shows the connected account's name and picture on this page.
  • video.upload — sends a video to the connected account's inbox as a draft.
